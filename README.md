# 仁和医院预约实验：研究员使用手册

本网页用于数字交互实验，所有院名、医师、就诊人和号源均为模拟数据，不产生真实预约。当前版本记录网页行为，不连接 Tobii，也不自动录屏。

## 1. 实验前准备

1. 在 Chrome 或 Edge 打开 index.html，或打开已发布的 GitHub Pages 链接。整场实验使用同一地址、同一浏览器，不使用无痕模式。
2. 固定显示器、屏幕分辨率、浏览器窗口大小和浏览器缩放（建议100%）。眼动校准后不要移动窗口或更换屏幕。关闭可能弹出的通知。
3. 确认 Tobii 独立采集和屏幕录制正常；验证眼动校准及时间同步。网页不负责启动这些设备。
4. 内部试做一轮，确认下载文件可打开、TASK_START/TASK_END齐全、AOI位置合理。
5. 使用参与者编号（如P001），不填写姓名或其他真实个人信息。

## 2. 开始会话

首页为“实验管理”。填写参与者编号，选择科室列表版本：
- 标准：8个科室。
- 精简：4个科室。

点击“开始新会话”，进入需求单。旧会话数据会被替换，请先导出备份。

版本选择只控制科室数量；当前任务顺序固定，没有随机化或自动平衡。正式实验需事先制定条件与顺序安排，不应随意临场切换。

## 3. 受试者如何操作

每轮共4个办理任务。受试者先阅读需求，再点击“进入预约网站”。此时记录TASK_START，开始任务计时；此前阅读需求的时间不计入任务时长。

受试者可以选择院区、科室、门诊类型、日期、医师、时间和就诊人，提交后在“我的预约”查看、修改或取消。医生均不限，日期固定为2026年10月12日至17日。

“查看需求单”可随时查看要求，打开/关闭均记录事件。“完成本次办理”对受试者可见，点击后立即结束当前任务并进入下一份需求；第四次完成后进入结束页。提交预约本身不会结束任务。

请提前向受试者说明完成按钮的含义。网页不设置超时，也不自动判定犹豫。若研究人员解释或帮助，应另外记录帮助时间与内容，并按实验协议统一处理。

## 4. 研究员控件：F8

参与者业务页面按F8打开研究员面板，再按F8关闭。部分笔记本可能需要Fn+F8。

面板提供：
- 放弃本次办理：确认后记录abandonment并进入下一任务。
- 研究员导出：尝试下载事件、提交和最终结果三个CSV，浏览器可能要求允许多个文件下载。

研究员面板默认不生成，不占受试者页面AOI；打开/关闭会记录research_panel_toggle。受试者的“完成本次办理”始终可见，不需要F8。

## 5. 导出与保存

结束页或实验管理页可分别下载：

| 文件 | 内容 |
| --- | --- |
| events.csv | 每次点击、页面变化、选择、AOI、任务开始/结束等事件 |
| submissions.csv | 每次预约提交，包括后来被修改的提交 |
| outcomes.csv | 每个任务结束时的最终结果和统计 |
| backup.json | 完整会话备份，包含事件、提交、最终结果及预约记录 |

每名参与者结束后保存全部文件，并与Tobii文件、录屏建立同一编号的文件夹。文件名包含参与者编号和会话ID片段。JSON用于完整保存，不是网页导入恢复文件。

数据自动存在当前浏览器localStorage，不会上传到GitHub或服务器。清理浏览器数据、换浏览器、换地址或开始新会话可能导致原记录不可用。下载后请核对文件内容，不要只检查文件名。

## 6. 时间字段

单位为毫秒，除以1000得到秒。事件CSV固定保留这些时间列；不适用的值留空。

| 字段 | 含义 |
| --- | --- |
| epoch_ms | Date.now()系统绝对时间，从1970年起算 |
| event_time_iso | 可读UTC时间，末尾Z表示UTC；不是本地时间 |
| task_elapsed_ms | 当前系统时间减本次TASK_START；任务外留空 |
| monotonic_ms | 相对本次页面加载的单调计时 |
| time_origin_ms | 浏览器本次页面计时起点 |
| task_duration_ms | TASK_END中的总时长，普通事件留空 |

TASK_START相对时间接近0，可能有数毫秒偏差。查看需求、无点击阅读、停顿和研究员操作均计入时长，没有暂停计时。相邻点击间隔不能直接标为犹豫。

任务相对时间目前依赖系统时钟，修改系统时间可能影响它。同次页面加载内的间隔可用monotonic_ms；刷新后该计时重新开始，不能直接跨加载相减。

## 7. 选择与最终结果

selection_change记录field、value、previous_value及is_target：
- true：该次显式选择符合需求。
- false：不符合需求。
- 空：需求未指定，例如医师不限。

TASK_START中的selection_snapshot记录默认选择。默认值不会被自动算作一次错误选择。

TASK_END事件与outcomes.csv含：

| 字段 | 定义 |
| --- | --- |
| trial_outcome | correct_final_booking / incorrect_final_booking / no_booking / abandonment |
| had_error | 是否存在错误选择或错误提交 |
| recovered | 存在上述错误且最终结果正确；只代表操作纠正，不代表认知恢复 |
| error_count | 不符合要求的显式选择次数＋错误提交次数；可能重复统计同一问题，不是独立错误数 |
| back_count | 点击更换科室、返回排班、修改时间、首页的次数；不统计浏览器后退 |
| edit_count | 在预约记录点击“修改预约”的次数 |
| task_duration_ms | 本次TASK_START至结束的总时长 |

正确最终结果要求：当前任务恰好有一条未取消预约，且就诊人、院区、科室、日期、时间、门诊类型均符合要求。两条未取消预约即使一条正确，也不会算正确最终结果。放弃单独记录。

is_target、matches_requirement、结果和需求答案仅用于标注与分析，不应作为预测模型输入，避免答案泄漏。

## 8. Tobii与AOI同步

TASK_START/TASK_END会记录网页时间，并让右下角方块短暂闪烁，可用于录屏初步对齐。这不是已验证的硬件同步。正式采集应结合具体Tobii型号和SDK建立时间映射，测量偏移与漂移，不能直接将设备时间与网页时间相减。

regions为JSON数组，保存AOI的x/y/width/height；坐标为浏览器内容区域CSS像素，随页面及滚动记录。Tobii通常使用屏幕坐标，需结合窗口位置、浏览器工具栏及缩放转换，并实测验证。

environment保存屏幕尺寸、viewport、devicePixelRatio和visualViewport.scale。visualViewport.scale不等于桌面浏览器缩放比例；浏览器zoom仍需人工固定和记录。隐藏研究员控件不属于默认AOI。

## 9. 刷新、中断及异常

- 刷新会返回实验管理页，可点击“继续当前任务”。已提交预约保留，未提交选择会重置，任务计时继续；会记录session_resume。该试次应标记为中断，分析时单独处理。
- 不要把刷新当作返回按钮，使用网页导航。
- 若下载被拦截，允许本站下载，或在管理/结束页分别导出。
- 若事件CSV缺少TASK_END，检查是否只提交预约、尚未点击完成。
- 若线上仍显示旧版，等待部署完成后Ctrl+F5刷新；本地文件和线上地址的数据相互独立。

## 10. 更新到GitHub Pages

将index.html、app.js、style.css、logo.svg放在仓库根目录，同名上传覆盖即可，不上传参与者数据。Settings → Pages → Deploy from a branch → main / root。更新README可同时上传本文件。
